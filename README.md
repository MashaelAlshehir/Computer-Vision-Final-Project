# Smart Football Player Analytics

## Project Overview

This project was developed as part of the **Computer Vision training program at SDAIA Academy**.

It demonstrates practical applications of computer vision using Python, OpenCV, YOLOv8, and other computer vision technologies. The project focuses on football player detection and tracking, team classification, player movement analysis, tactical zone visualization, and crowding detection.

The project applies computer vision techniques to a real-world football analytics scenario, with an emphasis on object detection, object tracking, image processing, and automated analysis.

## Project Objectives

- Detect football players using YOLOv8.
- Track players using ByteTrack.
- Classify players into teams.
- Generate player movement heatmaps.
- Visualize player movement trails.
- Divide the field into tactical zones.
- Detect player crowding situations.
- Integrate all analytics into one final video.
