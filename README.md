# Computer Vision Project

This project was developed as part of the Computer Vision training program at SDAIA Academy. It demonstrates practical applications of computer vision using Python, OpenCV, and YOLO, including object detection, oriented bounding box (OBB) detection, vehicle counting, and parking space availability detection.
The project focuses on applying computer vision techniques to real-world scenarios, with an emphasis on object detection, image processing, and automated analysis.
Training Program: SDAIA Academy – Computer Vision
Technologies: Python, OpenCV, YOLO, NumPy, PyTorch
SDAIA Academy: https://github.com/SDAIAAcademy
